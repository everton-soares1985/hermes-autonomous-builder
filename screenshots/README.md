# Screenshots

Only real, sanitized product evidence belongs here. V0 has no runtime interface, so no synthetic dashboard is presented as an implemented feature.

Before adding an image:

1. remove emails, account names and counts, tokens, private URLs, hostnames, IPs, paths, chat IDs, and notifications;
2. verify that no browser profile, terminal history, or environment value is visible;
3. use a descriptive filename and alt text;
4. record the related tested SHA in the pull request;
5. run the publication and confidentiality checks.
