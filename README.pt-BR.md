# Hermes Autonomous Builder V0 — resumo

Esta é a base documental, privada e sanitizada de um futuro agente autônomo para desenvolvimento de software. O repositório descreve três papéis independentes—Arquiteto, Coder e Revisor—coordenados pelo Hermes, com o OmniRoute escolhendo apenas a rota permitida dentro de cada papel.

O projeto combate “sucesso falso” exigindo testes reais, exit codes, diff limitado ao escopo, SHA imutável, evidências com hash e aprovação por um modelo diferente do autor. Somente o orquestrador pode emitir `DONE`.

Esta versão **não implementa nem executa o agente**, não altera VPS, serviços, combos, Telegram ou o Hermes existente, e não contém credenciais, identidades de contas nem inventários internos brutos.
